## 3. Natural-language search (master prompt, 16 Nov)

- Follow-ups refine the search on screen (182c051): "only YouTube" or "at least 50k" keeps the current search; a new
  niche or "start over" starts a fresh one with no filters carried over; a contradiction (at least 100K after at most
  50K) replaces the old bound and says so. The AI still reads only the new message; the combination is fixed rules on
  the server, shown to the user as kept / changed / removed, with "search this on its own instead". 8 unit tests; an
  API test with a mock model is in `creators-api.int.test.ts` (that suite needs Meilisearch).
- A purpose the applied reading named ("to promote a new phone") is repeated under the results as not checked (3038fd3).
- Not built (product decisions needed): campaign-aware recommendations and explanations.
- Not yet measured against the real model today: Groq's free allowance was used up.

## 4. Customer notifications (4da3121)

Credits low / very low, trial ending / ended, payment failed, subscription canceled and live search finished are now
emailed to the workspace's owners and admins (idempotent per event). `NOTIFY_EMAIL_MODE`: off (default, logged only),
test (recorded, nothing delivered), resend (real; needs `RESEND_API_KEY` and `NOTIFY_EMAIL_FROM`). Settings ›
Notifications has an "Account emails" switch (`users.preferences.emailNotifications`). Real delivery needs an email
provider and a running worker, which the owner cannot provide yet.
