## 3. AI / LLM security (OWASP LLM Top 10 2025; offline code review + simulation, no live model calls)

| ID | Finding | Status |
|---|---|---|
| A-1 | **One search result could act on others** (LLM01/LLM05). Up to 12 Google results share one relevance prompt and line breaks survived cleaning, so a snippet forged a line in the exact candidate format (`1. instagram @rival | Brand store…`) plus instructions — reproduced offline. Impact: a rival dropped from a customer's discovery results, or an invented reason ("Fake followers, avoid") shown on a delivered card. | **Fixed** `c966003`, `e16cf1d`: every whitespace kind collapsed to one line per candidate (tested with `\n`, `\r`, U+2028); a model reason is shown only when every specific word comes from that candidate's own handle, title or snippet (no credit for the request), else none (audit SEC-16). |

| OWASP | Exposure | Evidence |
|---|---|---|
| LLM01 Prompt injection | Partial → fixed (A-1) | All untrusted fields fenced (`fenced()` neutralises `<>`), contacts redacted; schema-validated replies |
| LLM02 Sensitive disclosure | Low | `redactContacts` before every prompt; reasons/summaries with links or contacts rejected |
| LLM05 Output handling | Low | Output only escaped text or checked enums/indices; never SQL, shell or HTML |
| LLM06 Excessive agency | None | No tools; code decides every paid fetch and credit charge, within caps |
| LLM09 Misinformation | Controlled | Niche quotes must be grounded; minor protection only switches on; AI country/city stored only as weak evidence |
| LLM10 Unbounded consumption | Controlled | Token/time limits per call, monthly budget guard, per-model cooldowns, interpret rate-limited per user, 300-char cap |
| LLM03/04/07/08 | N/A or none | Hosted models only; no fine-tuning; no secrets in prompts; no vector store |

Residual: a creator can misdescribe themselves in their own bio and the AI may repeat it (labelled an estimate).
